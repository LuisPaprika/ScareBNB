# 🎮 ScareBNB

A narrative-driven horror game inspired by online ghost stories, featuring immersive environments, atmospheric sound design, and
interactive systems to convey the story.

---

## 🎮 Controls

- W / A / S / D – Move  
- Left Mouse Button (LMB) – Interact, Pickup, Drop
- Left Control (LCtrl) - Crouch

---

## 🧩 Gameplay

Players move into an Airbnb with a strange and unsettling atmosphere, where they feel constantly watched. Players explore the environment by interacting with objects to trigger events and uncover the story.

---

## ▶️ How to Run

- Download build from Releases
- Run .exe

or

- Open project in Unity  
- Load scene: Mainmenu  
- Press Play
